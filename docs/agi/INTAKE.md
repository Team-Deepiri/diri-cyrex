# Intake — new ideas and sources

Drop new links/ideas here using the template below. Triage them (fill in Maps to / Disposition /
Owner), add the resulting task to the real doc it belongs in (`STATUS.md`,
`CYREX_AGI_IMPLEMENTATION_PLAN_V2.md`, or one of the rationale docs), then delete the entry from
this file — the task in that other doc is the record from then on, not a copy kept here.

This file only ever holds items that haven't been turned into a task yet. Don't add tasks
directly to the implementation plan without triaging here first — that's what keeps `STATUS.md`
honest about where things came from before they're fully scoped.
